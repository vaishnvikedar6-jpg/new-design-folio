## 🌿 Interactive Features

- **🌸 Interactive Character:** Authentic portrait with delicate floral framing and mouse-tracking tilt.
- **🎛️ Design Process:** 5-step interactive journey (`01 Discover` ➔ `02 Define` ➔ `03 Design` ➔ `04 Prototype` ➔ `05 Refine`).
- **✨ Custom Rose Cursor:** Desktop custom rose halo cursor with magnetic hover states.
- **📄 Printable Resume Modal:** Instant full-screen view of academic credentials (SIES GST Nerul — CGPA 9.86), hackathons, internships (Oasis Infobyte), and design stack.
- **🎉 Confetti Celebrations:** Tactile micro-delights on resume download and social connections.

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/vaishnvikedar6-jpg/new-design-folio.git

# Navigate to project directory
cd new-design-folio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Build for production:
```bash
npm run build
```

Deploy to GitHub Pages:
```bash
npm run deploy
```
